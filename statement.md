# Student Result Management System

## 1. Problem Statement

Managing student records and marks manually can be time-consuming and may lead to errors. There is a need for a simple system that can store student details and provide basic operations for managing their academic records.

The Student Result Management System is designed to provide a simple, menu-driven solution for adding student information, finding students, updating marks, and displaying student records.

---

## 2. Scope of the Project

The scope of this project includes:

- Adding student details such as name, roll number, and marks.
- Storing student records during program execution.
- Finding a student using their roll number.
- Updating student marks.
- Displaying all stored student records.
- Providing a simple menu-driven interface.

The current version is a basic Python application and stores data only while the program is running. It does not use a database or permanent file storage.

---

## 3. Target Users

The system is mainly intended for:

- **Students** – to understand and manage basic academic records.
- **Teachers** – to maintain basic student marks records.
- **College/School Staff** – for basic student result management.
- **Python Beginners** – to learn Object-Oriented Programming through a practical project.

---

## 4. High-Level Features

### 1. Add Student

Allows the user to enter and store a student's name, roll number, and marks.

### 2. Find Student

Searches for a student using their roll number.

### 3. Update Marks

Allows the user to modify the marks of an existing student.

### 4. Show All Students

Displays the details of all students currently stored in the system.

### 5. Student Not Found Handling

Displays an appropriate message when the entered roll number does not exist.

### 6. Menu-Driven Interface

Provides simple options for adding students, finding students, updating marks, viewing records, and exiting the program.

---

## 5. Project Limitations

- The system does not use a database.
- Student data is stored only while the program is running.
- Data is lost when the program is closed.
- The project is designed as a basic academic project and does not include advanced authentication or permanent data storage.

---

## 6. Conclusion

The Student Result Management System is a basic Python project that demonstrates how Object-Oriented Programming (OOP) concepts can be used to create a simple student record management application.

The system provides basic operations such as adding students, finding students, updating marks, and displaying student records through a menu-driven interface.
